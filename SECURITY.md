# Security Policy

## Supported Versions

The following versions of Vertofi are currently supported with security updates and vulnerability patches.

| Version                   | Supported |
| ------------------------- | --------- |
| Latest Production Release | ✅         |
| Previous Major Release    | ✅         |
| Older Releases            | ❌         |

## Reporting a Vulnerability

If you discover a security vulnerability in Vertofi, please report it responsibly.

### How to Report

Send an email to: [info@vertofi.com](mailto:info@vertofi.com)

Please include:

* Description of the vulnerability
* Steps to reproduce the issue
* Affected URLs, APIs, or components
* Screenshots or proof of concept (if available)
* Potential impact assessment

### Response Timeline

* Initial acknowledgment: Within 48 hours
* Preliminary assessment: Within 5 business days
* Status updates: Provided periodically during investigation
* Resolution target: Based on severity and impact

### Responsible Disclosure

Please do not publicly disclose security vulnerabilities until Vertofi has had a reasonable opportunity to investigate and resolve the issue.

### Scope

This policy covers:

* Vertofi Web Application
* Vertofi APIs
* Authentication & Authorization Systems
* Financial Data Processing Services
* WhatsApp Integrations
* Client Dashboards
* Business Intelligence Modules

### Security Commitment

Vertofi takes the protection of client financial data seriously. All reported vulnerabilities are reviewed, prioritized, and remediated according to their severity and potential impact.

Thank you for helping keep Vertofi secure.
